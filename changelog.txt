  Minor Features:
    - Option: Light and/or heavy armor get a micro or tiny equipment grid, respectively. (Default: Heavy. Grid sizes: heavy armor 4x3, light armor 2x3)

    - The reactive armor plating is now only be placable in vehicles, as it was inteded from the start.

    - Set this mod properly to be a [Space Age] mod, which it was from the start.

    - Internally set the grid definitions to be local variables to less spamming the global namespace.
    - Internally reframing the grid definitions and code.
    - Increased car grid size from 4x4 to 6x4, to be in line with other mods like [kry-vehicle-grids].
    - [ironclad-gunboat-and-mortar-turret] Added military-3 for the normal casting mortar bomb tech, and military-4 for casting clusterbomb tech. The clusterbomb requres military-4.
    - [scattergun turret] Switched backline mount from foundry to EMplant as it has more of these coponents. (breaking change)
  Graphics:
    - Changed the icon for all armor plating to something independent.
    - Added tint for tungsten and uranium shotgun pelets to make them slightly more distinguishable.
    - Removed overlayer from light and heavy armor plating tech icon.
  Compatibility:
    - Updated dependency of [OCs Base Assets] to >=0.4.0 as helper functions were updated. (makes it incompatible with older versions)
    - Made compats for [aai-vehicles-ironclad], [Ironclad gunboat and mortar turret], and [stratetic mortar ammo] independent of each other.
    - Removed compatibility for [UraniumShotgunShell], as it is integrated into this mod.
  Bugfixes:
    - Added missing localisation for [Uranium Artillery Shell] compatibility.
    - Heavy artillery shells were unable to unlocked if "casting-explosive-ammo-tech" was disabled, now fixed. The casting recipe is still not added in this case. (thanks to GingerBeard118 for reporting)
    - Hopefully fixing the startup crashes regarding missing ammo recipes.
    - [aai-vehicles-ironclad] Fixed that the ironclad casting recipe was not added when the setting was on.
    - [K2SO] Now support K2S0>0.5.0 which changed some internal names breaking my compat file. This should fix some startup crashes.
    - [strategic-mortar-turret] Fixed that the cryo-mortar-light-nuclear-ammo was unable to be unlocked.
    - [strategic-mortar-turret] Added missing localisations.
    - [strategic-mortar-turret] Fixed issues if some of the mortar ammo is not enabled by its mod settings.
    - [strategic-mortar-turret] Fixed some issues if [Ironclad gunboat and mortar turret] is not present.
    - [vtk-cannon-turret] Fixed that the turret casting recipes were not created.
    - [vtk-cannon-turret] Fixed that exlosive cannon shell magazine was not created.
